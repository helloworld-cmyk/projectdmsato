
## Lưu dữ liệu trên GitHub Pages

GitHub Pages là hosting tĩnh nên trình duyệt không thể ghi ngược dữ liệu vào file JSON trên repository. Ứng dụng lưu các thay đổi đặt sân, kèo và chat bằng `localStorage` của trình duyệt; dữ liệu vẫn được giữ khi tải lại trang trên cùng thiết bị/trình duyệt.

Muốn đồng bộ thật giữa nhiều người dùng hoặc nhiều thiết bị cần backend/database.
